## Quick Overview

This project provides Python code for text mining analysis of early Nigerian newspapers (1880s-1930s) published in Lagos. It analyzes geographical representations, collective identity, and discourse patterns during the colonial period.

本プロジェクトは、1880-1930年代のラゴスで発行されたナイジェリア初期新聞のテキストマイニング分析を行うPythonコードです。植民地時代における地理的表象、集団的アイデンティティ、言説パターンを分析します。
